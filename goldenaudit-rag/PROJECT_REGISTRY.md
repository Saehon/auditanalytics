## Integration contracts
- AuditGold → original prompts and expert gold only after blinded adjudication.
- POMELO → evidence passport and authority version gate.
- DARWIN V9 → falsification/claim review and reproducibility checks.
- CAM/KAM + ICFR → hard task families; protected source data never pushed into public code.
- ESG → dated assurance evidence and materiality scenarios.
- JMIS multi-agent → coordination and human-authorization benchmarking.
- MACEI → optional management-accounting cost and resource-efficiency case families.
- IFRS-AI-Inspector / IFRS-PCAOB-AI → accounting standard/version stress tests.

Important: 'link to all projects' means **registry links**, not a claim that all GitHub/Drive projects were modified or have bidirectional integrations.
